# Mục tiêu

Quản lý toàn bộ Prompt của hệ thống.

Mỗi AI Agent chỉ có một Prompt chính thức.

Prompt được quản lý tập trung tại tài liệu này.

Không lưu Prompt trong

- Python
- Code Node
- FastAPI
- Database

Mọi thay đổi Prompt đều cập nhật tại đây.
